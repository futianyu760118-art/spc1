> **版本**：v2.0

## 一、设计总纲

规划分两个维度展开，二者必须配套：

| 维度 | 主线 | 核心动作 |
|---|---|---|
| **后端能力（五层）** | 产能 → 工时 → 物料 → 时间窗口 → 执行 | 修正现状盘点，补齐缺口 |

## 六、关键设计规则（开发必须遵守）

### R1. time_zone 动态派生（不存字段）

time_zone 是查询时派生字段，**不存储在 `production_schedule_plan` 表中**（today 每天变化，入库固化会腐烂）。

```sql
-- 查询时动态派生
SELECT
  *,
  CASE
    WHEN plan_date = CURRENT_DATE THEN 'today'
    WHEN plan_date BETWEEN CURRENT_DATE + 1 AND CURRENT_DATE + 3 THEN 'frozen'
    WHEN plan_date BETWEEN CURRENT_DATE + 4 AND CURRENT_DATE + 10 THEN 'material'
    ELSE 'pending'
  END AS time_zone
FROM production_schedule_plan
WHERE plan_date >= CURRENT_DATE
```

> ⚠️ **索引注意**：`list_schedule_plans` 支持 `time_zone` 过滤时，WHERE 条件必须展开为对 `plan_date` 本身的范围条件（如 `plan_date BETWEEN CURRENT_DATE+1 AND CURRENT_DATE+3`），**不要对 `CASE ... END` 结果做 WHERE**，否则跳过 `plan_date` 索引全表扫描。

### R2. 今日栏"在产"口径（区间相交）

**一句话定死**：今日栏（🔴）整栏口径 = "今天在产"（区间相交）；冷冻/配料栏口径 = "未来开工"（`plan_date` 归属）。

| 栏 | 列表口径 | 统计口径 | SQL 条件 |
|---|---|---|---|
| 🔴 今日 | 区间相交 | 同左 | `start_date <= today AND end_date >= today` |
| 🟡 冷冻 | `plan_date` 归属 | 同左 | `plan_date BETWEEN today+1 AND today+3` |
| 🟢 配料 | `plan_date` 归属 | 同左 | `plan_date BETWEEN today+4 AND today+10` |

- 今日栏的 bucket（精益/组装/包装）筛选器只作用于"在产"计划集合，不跨栏
- 冷冻/配料区一个计划只出现在一个区（按 `plan_date` 即开工日归属），三栏计划列表互不重复
- 今日栏区间相交覆盖所有正在生产的单（含跨日在产），与分桶归属解耦

### R3. 配料区双视图（计划视角 + 物料视角）

**配料区主轴 = 物料需求日**（哪天要用料），排产日期作为参考信息叠在卡片上。仓库备料看的是"哪天要用料"，不是"哪天排产"。

| 视图 | 位置 | 形态 | 受众 |
|---|---|---|---|
| 计划视角卡片 | 驾驶舱配料栏 | 一个卡片 = 一条排产计划，缺料状态角标（红/黄/绿） | 计划员概览 |
| 物料视角清单 | 物料需求看板（下钻） | 按物料 × 需求日期展示备料清单 + 缺口明细 | 仓库/采购 |

- 两个组件**独立渲染，不混用**
- 入口连通：配料栏卡片点"催料"/"BOM" → 跳物料需求看板，预筛选该订单的物料需求

### R4. kpi-summary 渐进式上线

kpi-summary 字段分阶段接通，未接通的格子显示 `--`，不假装有数据：

| 阶段 | 接通字段 |
|---|---|
| 1a | `today.{target_qty, completed_qty, completion_rate}` + `pending.todo_count` + `anomalies`(mock，用最终 schema) |
| 2 | `frozen.locked_count` + `frozen_break_count` |
| 3 | `material.{kit_ready_rate, shortage_count, eta_delay_count}` |
| 4 | 异常驱动全量 + 阈值规则接入 |

**总周期**：6.5–7 周（较原 6 周略增，但风险大幅降低）。

**关键原则**：
- 态势条和驾驶舱**共用一份 kpi-summary 数据**，阶段 1a 一起做，一次开发两个形态，不重复
- 性能优化提到**阶段 2 开头**（先修地基再加冷冻逻辑），不放在最后
- 装配拆分验证可与阶段 1/2 并行（由另一人实跑），不卡版面改造

## 八、最终效果（各角色视角）

- **计划员**：登录 → 驾驶舱首页 → 红栏今天在产单进度、黄栏 8 单锁定、绿栏 3 单缺料。插单只动配料区；动冷冻区弹强制理由框。
- **产线班长**：只看红栏 → 今天在产单的应产/已完成/进度条 → 点进去填报当日产量、报异常。
- **仓库**：物料需求看板 → 未来 7 天每天备料清单（按物料需求日）+ 缺口 → 按天备货。
- **采购**：缺料订单 + 对应 PO 的 ETA → 延期标红 → 一键催料。
- **管理者**：任何页顶部态势条常驻，异常自动飘红提醒，点开抽屉看详情，再跳驾驶舱深看。
- **领导**：三栏红黄绿 + 态势条，一眼知全局；可加投屏模式（隐藏操作按钮、放大字号、自动刷新）周会用。
