品质管理 · 供应商索赔单 · 原型

把纸质「供应商索赔通知单」线上化：台账 + 新建（纸质单实时预览）+ 详情（左纸质单右审批面板，四态演示）+ 打印同源版式；待办收口审批中心

01

索赔单台账

KPI 带 4 卡（本月索赔金额 / 审批中 / 待我审批 / 已归档，点击即筛）；状态 chips（radio-hack 真实过滤）+ 更多筛选抽屉菜单（含空态演示）；密集表格：单号 mono 链接 / 状态标签 / 供应商组合列 / 原因标签 / 细项 mini 标签 +「+N」/ 金额右对齐 / 当前节点 + 等待时长（超时红）/ 附件计数 / 行 hover 操作；聚合行（合计 ¥23,550）+ 提交 / 删除二次确认弹窗。

R关键规则原型中每一处交互都对应下面一条规则，实现时按此校验
规则说明
审批链快照冻结提交时按当前金额冻结审批链快照，在途单据不受配置变更影响；金额 ¥3,260 ≥ ¥1,000 含「上级部门意见」，< ¥5,000 不含「总经理意见」（原型以虚线跳过标记呈现）。
默认审批链索赔部门意见（采购经理）→ 上级部门意见（供应链经理，≥ ¥1,000）→ 总经理意见（≥ ¥5,000）→ 财务结算（无条件）；阈值与节点在审批中心配置。
状态机draft → pending → approved | rejected | recalled；驳回 / 撤回后可编辑重新提交，审批记录按轮次留档不覆盖。
驳回必填意见通过可不填意见；驳回必须填写原因，退回申请人修改后重新提交。
操作权限编辑 / 提交仅本人草稿（或驳回 / 撤回态）；审批仅当前节点审批人 / admin；已归档删除需「归档删除」权限。
打印同源详情页左侧纸质单与打印页同一版式家族；归档后按此打印 / 另存 PDF，归档前亦可预览。
待办收口「待我审批」不单设页面——统一收口到审批中心待办工作台（biz_type = supplier_claim），侧栏保留待办计数。
本次范围 仅供应商索赔单 4 页 + 模块总览；把现有 AntD 实现重设计为全站「靛蓝精致版」范式，不新增后端字段。
未纳入本次 品质总览看板、品质异常台账、质量追溯（对外接口已存在，无前端页）——待品质域扩展时另行设计。
