# 品质管理（供应商索赔单）重设计原型设计文档

- 日期：2026-09-23
- 状态：已与用户逐节确认（方案 A：台账 + 文档化详情），待实现
- 范围：仅「供应商索赔单」4 页 + 模块总览，输出 HTML 原型
- 风格基准：`docs/prototype/redesign/`（靛蓝精致版设计系统）
- 业务实现参照：`docs/superpowers/specs/2026-09-22-supplier-claim-design.md`（已上线的功能设计）

## 1. 背景与目标

线上「品质管理」目前仅供应商索赔单一页（列表 / 新建编辑 / 详情审批 / 打印，AntD 实现）。
全站重设计原型（`docs/prototype/redesign/`）已覆盖 55+ 页，品质管理尚未纳入。

目标：按全站重设计规范产出品质管理模块 HTML 原型（零依赖、离线可看），
评审通过后作为 React + AntD 落地的视觉与交互基准。

## 2. 已确认决策

| 决策点 | 结论 |
|---|---|
| 范围 | 仅供应商索赔单（列表 / 新建编辑 / 详情审批 / 打印）+ 模块总览；不含品质总览、品质异常、质量追溯 |
| 文件组织 | 独立子目录 `docs/prototype/quality-center/`，复用 `../redesign/styles.css`（approval-center 先例） |
| 交互深度 | 静态高保真 + 局部交互（CSS `:has()` + 极少量原生 JS） |
| 改进尺度 | 允许体验优化（KPI 带、快速视图 chips、纸质单预览、四态切换等），不涉及后端新字段 |
| 方案 | A：台账 + 文档化详情——列表沿用全站普通页范式；详情左纸质单右审批面板；新建带纸质单实时预览 |
| 待办收口 | 不设「待我审批」页——已收口到审批中心（与线上实现一致，侧栏仅一个菜单项） |

## 3. 文件结构

## 4. 页面设计

### 4.1 列表 `claims.html`

- 工具栏：搜索（单号/供应商/申请人）+ 状态 chips（全部/草稿/审批中/已驳回/已撤回/已归档，带计数）+ 更多筛选 / 刷新 / 导出 + 主按钮「新建索赔单」
- KPI 带 4 卡（点击即筛）：本月索赔金额 / 审批中 / 待我审批（hot）/ 已归档
  （实现注：需列表接口返回各状态计数 stats 或前端统计，落地时定）
- 表格 11 列：索赔单号（mono 链接）/ 状态 / 供应商（名称+编码两行）/ 索赔原因 / 索赔细项（≤3 tag + “+N”）/ 索赔金额（右对齐加粗）/ 开单日期 / 申请人 / 当前节点（审批中显示节点名 + 已等待时长，超时红）/ 附件数 / 操作（hover 浮出：查看·编辑·提交·删除）
- 底部聚合行：合计 N 单 · 金额合计；分页；空态示例
- 交互：chips radio-hack + `:has()` 真实筛选、行 hover、行点击进详情

### 4.2 新建 / 编辑 `claim-new.html`

- 顶部条：返回 + 标题（新建 / 编辑 `SC20260923-004`）+ 右侧「仅存草稿」「保存并提交审批」
- 左主表单（约 62%）三张卡：
  1. 基本信息：供应商搜索选择器（名称+编码）/ 开单日期 / 索赔原因（两选 radio 卡片，中英）/ 退回要求（两选 radio 卡片，中英）
  2. 索赔细项与金额：8 个 checkbox 卡片（中英标签）+ 索赔金额（大号输入 + 元）+ 索赔方式
  3. 说明与凭证：金额计算说明（textarea + 质量协议条款提示条）+ 备注 + 附件拖拽区 + 已传文件列表
- 右侧粘性「纸质单预览」：按打印版式缩放渲染（预填示例数据），标注「随填写实时更新」+「金额计算说明将原样打印在单据上」

### 4.3 详情 `claim-detail.html`

- 顶部条：返回 + 单号 mono + 状态 tag + 操作按钮（打印/导出 PDF、编辑、提交审批、撤回单据、反审核，按状态显隐）
- 左 60%：纸质单版式只读渲染（与打印同源），审批签字区随进度填充（已审节点显示意见 + 签字人 + 日期，未到节点留空）
- 右 40% 粘性审批面板：
  - 状态卡：状态 tag + 申请人/提交时间 + 当前节点 + 已等待时长（超时红）
  - 审批进度：4 节点步骤条 + 多轮历史存档标记
  - 当前节点操作区：意见框 + 通过/驳回（仅审批中且有权；无权显示提示文案）
  - 审批记录：按轮次分组 timeline（通过绿 / 驳回红 / 撤回橙 / 提交蓝）
  - 附件列表
- 右上角「演示态切换」小控件（草稿/审批中/已归档/已驳回，标注"原型演示"）；一处二次确认弹窗示例（撤回）

### 4.4 打印 `claim-print.html`

- A4 比例白纸（900px）纸质单：公司抬头（宁波恒剑光电科技有限公司 / IQC Department）+ 中英标题 + NO./Issue date → 供应商 → 索赔原因（■□ + 固定条款）→ 索赔细项（☑□ 八项）→ 索赔方式 + 计算说明 + 共计扣除费用 + 品质部签字 → 退回要求 → 各级意见/签字 → 备注
- 顶部工具栏（`no-print`）：返回详情、打印 / 另存为 PDF + 页脚提示「目标选『另存为 PDF』」；`@media print` 去背景

### 4.5 模块总览 `index.html`

- 模块定位 + 4 页导航卡 + 关键规则：审批链提交时冻结快照、多轮审批留档、金额阈值条件节点（≥1000 上级 / ≥5000 总经理）、详情与打印同源、归档前也可预览打印
- 明确「待我审批」收口到审批中心，品质管理不单设待办页

## 5. 设计系统与样式约定

- 全部 token 走 `redesign/styles.css` CSS 变量，不新造色值/字号
- 状态 tag 映射（对齐线上 CLAIM_STATUS_MAP）：
  - draft 草稿 → `tag-status-wait`（灰）
  - pending 审批中 → `tag-status-kit`（info 蓝）
  - approved 已归档 → `tag-status-done`（绿）
  - rejected 已驳回 → danger 红软底
  - recalled 已撤回 → warning 琥珀软底
- 索赔原因 tag：现场/客户投诉 → danger 软底；供货业绩 → info 软底
- 金额 / 日期列右对齐 + `tabular-nums`；单号 mono
- 纸质单版式：1px `#000` 边框表格、中英双语、■/☑ 勾选符、黑白打印友好

## 6. 演示数据口径（全模块共用）

- 8 条索赔单覆盖 5 种状态；`SC20260923-004` 为列表/详情/打印共用主数据（审批中，停在第 2 节点，金额 ¥3,260.00）
- 审批链 4 节点：索赔部门意见（采购经理）→ 上级部门意见（供应链经理，≥1000）→ 总经理意见（≥5000）→ 财务结算
- 供应商示例带编码（如 SUP-00231）；申请人 = 当前演示用户「王华」或品质部演示角色

## 7. 交互清单（原型级，均零依赖）

| 交互 | 实现方式 | 所在页 |
|---|---|---|
| 状态 chips 真实筛选 | radio-hack + `:has()` | claims |
| 行 hover 操作浮出 / 行点击跳详情 | CSS + `<a>` | claims |
| 纸质单预览静态展示 | 纯 HTML/CSS | claim-new |
| 四态切换（草稿/审批中/已归档/已驳回） | ~10 行原生 JS | claim-detail |
| 撤回二次确认弹窗 | `:has()`/checkbox hack | claim-detail |
| 打印隐藏工具栏 | `@media print` | claim-print |

## 8. 交付与验证

- 双击任意 html 离线可看（无 CDN、无构建）；浏览器控制台无报错
- protobar 全链路可达（含回 `../redesign/index.html`）；侧栏互链正确
- `redesign/index.html` 新增 M11 分组且链接有效
- 字号 / 间距 / 色板符合 `design-system.html` 规范（不自造样式）

## 9. 不做（YAGNI）

- 不做品质总览看板、品质异常、质量追溯（用户明确排除）
- 不做跨页数据流转的可点击演示（仅静态高保真 + 局部交互）
- 不改任何生产代码（唯一例外：`redesign/index.html` 加 M11 入口）
- 不引入框架、构建步骤或新增依赖
